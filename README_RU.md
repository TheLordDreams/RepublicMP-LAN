# RepublicMP LAN 0.7.2-lan2-rc1 — экспериментальная сборка

Доработка LAN-альфы от 25 октября 2026 года. Для Workers & Resources: Soviet Republic **1.1.1.9, Steam build 23935965**, Windows x64. Другие EXE/движки отклоняются проверкой SHA-256.

Добавлены настройки сетевого ожидания, ограничение зависших отправок и ответов, отмена ожидающих операций при отключении, приём города через временный файл. Подробности — `ИЗМЕНЕНИЯ_RU.md`, результаты — `QA_RESULTS.json`.

**Проблема периодической повторной синхронизации из семи этапов не объявляется полностью исправленной.** В прежнем клиентском журнале обнаружены восемь расхождений зданий/жителей. Настройки ожидания сети не устраняют ошибки симуляции. Эта сборка остаётся кандидатом, а не стабильным релизом.

## Подготовка и запуск

1. Распакуйте ZIP в новую папку с коротким путём, отдельно от игры и старого мода. Не используйте symlink/junction. Каждому игроку нужна собственная законная копия точной версии игры.
2. В PowerShell из папки пакета выполните, указав свою установку:

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\Prepare-Coop.ps1 -GameDirectory "C:\Games\SovietRepublic"
```

Скрипт проверяет файлы и создаёт физическую копию в `local/game`. Оригинальные сохранения и настройки не копируются. Требуется место размером с игру. Папка назначения не перезаписывается.

3. Откройте свой Steam и выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\Launch-Coop.ps1
```

Если Windows пометила архив как скачанный, после проверки источника и контрольной суммы разблокируйте сам архив через его свойства до распаковки. Постоянно изменять политику PowerShell не требуется.

Хост загружает новый тестовый город → MULTIPLAYER → HOST → Co-op → HOST THIS CITY. Друг выбирает JOIN и вводит IPv4 хоста. Нужны общая LAN либо уже настроенная VPN и доступные TCP 5556/5560. Firewall, маршрутизатор и VPN скрипты не меняют. Steam-приглашения и relay не используются.

Оба игрока должны использовать **одну и ту же DLL 0.7.2-lan2-rc1**. Смешивать с lan1 нельзя. Для первого запуска используйте новый тестовый город; важные города оставьте в старой копии.

## Настройки

Кнопка «Настройки сети» доступна в меню MULTIPLAYER. В дополнительном окне мода — одноимённый раскрывающийся раздел. Сетевые таймауты меняются до подключения; сохраняются в `RepublicMP.profile.ini` рядом с DLL. Правило повторной синхронизации задаёт хост. Отключение автоматической синхронизации оставляет расходящиеся миры разными до ручного восстановления.

## Проверка и исходники

DLL собрана без ошибок/предупреждений. Прошли 12 автоматических тестов реальной TCP-реализации. Точные завершённые игровые прогоны, в том числе неудачные, перечислены в `QA_RESULTS.json`. Проверки двух копий на одном ПК не доказывают работу двух разных компьютеров.

`sources/` содержит соответствующие исходники мода, загрузчика и лицензии. Сборка: `sources/RepublicMP/tools/Build-Local.ps1 -Transport Lan`; сетевые тесты: `sources/RepublicMP/tools/Test-Network.ps1`. Нужны MSVC v145, Windows SDK 10 и C++20. Игрокам компилятор, Node и Python не нужны.

Основа: [E3418/RepublicMP](https://github.com/E3418/RepublicMP), загрузчик [MaxLegend/TesmioLoader](https://github.com/MaxLegend/TesmioLoader). Изменения GPL-3.0-only. При передаче другу сохраняйте исходники и лицензии вместе с DLL. Не распространяйте `local/`, игровые файлы и сохранения.

`history/lan1/` содержит исторические отчёты только прежней DLL. Их результаты не приписываются новой сборке. Пакет автоматически нигде не публикуется.
